category: Added

`slicer snapshot --parts deps` adds the `deps` part: the value `slicer deps --json` prints for the project. It is opt-in, so a call with no `--parts` prints the same five parts as before. `slicer snapshot --since FILE` takes a previous snapshot reply (`-` reads stdin) and prints `{revision, unchanged: true}` with no value for each part whose revision the file holds for the same project root and part name; a missing or unreadable file, or JSON with no `projects` list, is `usage` (exit 2) before any project is read. Slicer still loads and builds every part (s456).
