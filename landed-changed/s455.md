category: Changed

Startup is faster: `slicer --version` and `--help` import no command handler, no store, checker or renderer, and no `dataclasses`; each command's handler is imported only when that command runs, and `list`, `show` and `next` no longer import the renderer or `ops` unless they use them. `slicer --version` takes about 17 ms where it took about 80 ms, and `list --json --lean` about 87 ms where it took about 102 ms on this repository's store (best of five). Output, stderr and exit codes are byte for byte the same. The parser's base class, flag helpers and exit codes now live in `cli_args` (re-exported by `cli_common`), and the name lists the help prints in `vocab`; `ai.PROMPT_NAMES`, `note_pack.TRUST` and `snapshot.PARTS` keep working. A new test, `test_startup_imports`, guards the module names loaded by `--version`, `--help` and `list` (s455).
