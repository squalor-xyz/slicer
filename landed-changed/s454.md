category: Added

Per-slice changelog entries: `slicer changelog add ID --category NAME (--text TEXT | --stdin) [--replace]` writes `landed-changed/ID.md` (a `category: NAME` line, a blank line, the entry text), so parallel slice branches no longer edit one shared `CHANGELOG.md` and conflict at landing. `slicer changelog assemble [--dry-run]` writes every entry under the Unreleased heading in one layout (a `### CATEGORY` subsection per category in `changelog_categories` order, highest item id first, bullets joined) and deletes the files; `slicer changelog import [--dry-run]` splits an existing Unreleased body into entry files once. Five new config keys, off until `changelog_path` is set: `changelog_path`, `changelog_entries_dir` (default `landed-changed`), `changelog_unreleased_heading`, `changelog_categories` and `changelog_require_entry`. `check` reports a malformed entry file, a file named for no item and two files for one item; with `changelog_require_entry` on, `handoff` and `land` warn on stderr for an item with no entry. This repository adopts it: its entries go in `landed-changed/` (s454).
