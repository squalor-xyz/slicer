category: Changed

The snapshot's schema version is 2. Its `items`, `goals` and `runs` parts now hold exactly what `slicer list --json --lean`, `slicer goals --json` and `slicer relay-run list --json --active` print for the project, so a caller decodes a snapshot part and a command's output with one type. Item rows no longer carry `held` and `blocked` (`status.held` and `status.blocked` still give the ids), `goals.records` is an object of `goal` and `non_goal` lists, and `runs` is `{"runs": [...]}` with each run's `begun_at`, `counts`, `outcome` and full steps.
