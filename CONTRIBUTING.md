# Contributing

slicer supports Python 3.11+ and keeps its runtime and test suite standard-library
only. Discuss any proposed dependency with the maintainers before adding it.

Read [AGENTS.md](AGENTS.md) for contributor setup, required checks, house style, and
the roadmap-driven workflow. For a non-trivial change, also read
[ARCHITECTURE.md](ARCHITECTURE.md) for the design and invariants the change must
preserve.
